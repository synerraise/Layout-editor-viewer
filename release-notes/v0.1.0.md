# Layout AI Agent 0.1.0 Early Access

This is the first public trial release of Layout AI Agent for Windows x86-64.
Layout AI Agent is developed and published by **SynerRaise**.

## Included workflows

- Open, inspect, navigate, and render GDSII layouts
- Create layouts and cells
- Layer visibility and layer-property workflows
- Selection, movement, basic geometry editing, Undo, and Redo
- Rulers, viewport navigation, and cell hierarchy navigation
- Application-specific OA-like projects and GDS stream import/export

## Important limitations

- Early Access and not qualified for signoff or tape-out decisions
- OA-like projects are not Cadence OpenAccess databases
- Installer and executable are currently unsigned
- Windows is the initial public trial platform
- Back up original layouts and independently verify exported GDS files

## Installation and rollback

Accept `LICENSE-EULA.txt`, then verify `lagent_0.1.0_x64-setup.exe` with
`SHA256SUMS.txt` before installation.
Install for the current user. To roll back, uninstall version 0.1.0 and reinstall
the earlier package; never overwrite the only copy of a layout during testing.
